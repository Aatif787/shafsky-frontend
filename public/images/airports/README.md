# Shafsky Airport Image Assets Directory

This directory contains verified, high-resolution imagery for all 20 airports serviced across India.

Each subfolder is named after the airport standard 3-letter **IATA code** (in lowercase).

Every image has a self-describing filename indicating the specific terminal or landmark it depicts for effortless future maintenance.

---
